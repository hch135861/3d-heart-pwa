# 公交通勤助手 v2.1.0

唯一公开入口：`v2.html`。这是读取第三方实时公交接口的前端，不是运营方官方 GPS 服务。

## v2.1 通勤模式

- **步行时间 + 预留余量**：默认步行 4 分钟、余量 1 分钟，本地记忆设置。
- **现在要不要出门**：只使用通过异常校验、未过期且站点匹配的民辉方向记录计算。
- **赶不上首班时自动看下一班**：不再单纯把“最早到站”当成“最适合坐”。
- **数据可信度**：按站点匹配、剩余站数、等待时长和到站时刻的完整性/一致性分级；不代表运营方保证。
- **同车 ETA 趋势**：只有接口提供车辆标识时才比较上一次预估，避免把不同车辆误当成同一辆。
- **到站提醒**：浏览器允许通知时，可在新的可信预估进入提醒阈值后通知；这是页面刷新触发的本地提醒，不是后台推送。
- **独立 PWA 信息与公交图标**：添加到主屏幕后显示为公交工具。

## 数据安全规则

1. 1970、零时间戳、过期/远未来日期、无单位数字不参与 ETA。
2. `23站 + 0分钟` 这类矛盾组合不会成为推荐。
3. 请求失败、离线或超过 45 秒的记录停止推荐。
4. 旧记录不会在本地倒计时到零；ETA 只在成功刷新后变化。
5. “民辉方向”只匹配终点为 `民辉 / 民辉站 / 公交民辉站`，不猜途经站。
6. 通勤建议是“到上车站”的估算与步行时间比较，不是到目的地的乘车用时。
