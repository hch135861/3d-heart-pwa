# 公交页面 v2.0.0

这是读取第三方接口的前端，不是运营方实时 GPS 服务。新版入口 `v2.html` 与 `index.html` 相同；独立入口和带版本的资源文件用于避免复用旧页面。

## 分层

- `domain.v2.mjs`：严格的时间、站数解析，站名/终点匹配，异常隔离、去重和新鲜度判断。
- `app.v2.mjs`：按方向独立管理请求、失败与旧记录，取消旧查询，安全 DOM 渲染。
- `theme.v2.css`：窄屏适配，输入框不会撑开视口，底部刷新/暂停控制。
- 根目录 `service-worker.js`：公交路径使用 network-only/no-store；爱心页继续保留离线缓存。

## 可信度约束

1. 空值、零时间戳、非法日期、过期/远未来日期不能变成即将到站。
2. 秒/毫秒时间戳只用于绝对时间字段；不把无单位数字猜成分钟。
3. 原始到站日期无效时，同条记录的等待时长也隔离；23站+0分钟不能推荐。
4. 日期与等待时长明显矛盾时不推荐；没有有效时间就明确显示时间待确认。
5. 无时区的完整日期按 UTC+8 解析；只有钟点而没有日期时不擅自补今天。
6. `receivedAt` 是本页面获取时间，不是车辆定位更新时间。接口没有提供后者。
7. 请求失败、离线或45秒未成功获取的数据不能成为首选。切换筛选不能把旧记录重新标成新数据。
8. 不在前端倒数生成新的到站预估；收到成功空结果会移除旧车；更换站点会清除旧站数据。
9. “民辉方向”只匹配终点，不宣称覆盖途经民辉的全部线路；只有返回分组与上车站精确匹配才推荐。

## 验证

`node --test tests/bus-domain.test.mjs tests/bus-worker.test.mjs`

浏览器复现：`python tests/bus-browser.py`（需要 Playwright 和 `/usr/bin/chromium`）。浏览器测试在本地内联加载 HTML/CSS/JS、注入模拟 fetch；不验证公网模块加载、实际 iPhone Safari 或运营方车辆位置。测试数据来自截图场景和人工构造，绝不注入生产页面。

本次开发环境无法解析实时接口域名，未声称验证当前台州的车辆 ETA。页面依然请求原接口，没有引入公共代理、第二数据源或付费服务。
